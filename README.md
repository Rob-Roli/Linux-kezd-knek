A repository tartalmaz PDF-eket, amik segítenek kezdő linux felhasználókanak, akik ismrkednek a rendszerrel. Emellet tartalmaz egy extra PDf-et, amiben több szolgáltatás kipróbáltam virtuális gépen és ezt ledokumentáltam, tippekkel együtt (Ez még a kezdő éveimből van, de pont ezért gondolom azt, hogy ezt könnyebb megérteni kezdőként).
